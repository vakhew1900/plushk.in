## [Unreleased]

## [0.2.6] - 2026-09-18

### Исправлено
- Дополнительные поля страницы (`extras`, например хаб/тег статьи через `PageMatchGroup`) не извлекались вообще ни в одном Chromium-браузере (Chrome, Yandex, Edge и др.) при быстром сохранении — только в Firefox. Причина: список селекторов пересылался в контент-скрипт как `Map`, а Chrome-совместимый `browser.tabs.sendMessage` JSON-сериализует сообщение и превращает `Map` в `{}`, тогда как Firefox использует structured clone и сохраняет её как есть.

## [0.2.5] - 2026-09-18

### Добавлено
- Уведомление об успешном (или неуспешном) сохранении правила в редакторе — как в диалоге экспорта/импорта.

### Изменено
- Несохранённые изменения в редакторе правила теперь не теряются при переключении на другое правило — восстанавливаются, если вернуться обратно; сбрасываются только при уходе со вкладки Rules.
- Уведомления теперь закрываются сами через 2.5 секунды вместо 5.
- Из редактора правила убрана кнопка «Тест на текущей странице», которая ни к чему не была подключена.

## [0.2.4] - 2026-09-12

### Исправлено
- `PageMatchGroup`: CSS/XPath-селекторы для дополнительных полей закладки (например, хаб или тег статьи) теперь учитывают все подходящие элементы на странице, а не только первый — раньше при нескольких совпадениях (скажем, несколько хабов подряд) в правило попадал только самый первый из них, из-за чего условие могло не сработать, даже если нужное значение реально было на странице.

## [0.2.3] - 2026-09-11

### Добавлено
- Пресеты тегов и категорий по умолчанию при первом запуске расширения, с автоопределением языка браузера (русский/английский).
- README на английском и русском с инструкцией по составлению правил (JSON DSL) с помощью ИИ.

### Исправлено
- Крупные иконки закладок (карточка в «Библиотеке», превью в настройках закладки) больше не растягивают обычную фавиконку Chrome (запрашивается фиксированным размером 32×32) на весь блок — вместо размытой картинки в таких местах теперь показывается цветной плейсхолдер, если для закладки не задана настоящая обложка (правило иконки или ручной override).

## [0.2.0] - 2026-08-27

### Добавлено
- Визуальный конструктор условий для правил (ConsView) с поддержкой вложенных под-правил.
- Раздел «Дополнительно» в попапе быстрого сохранения и в редакторе правил: ручной выбор тегов/категории или подсказка по сработавшему правилу.
- Поиск и фильтрация закладок по тегам, категории и папке.
- Кастомные иконки закладок: движок правил для иконок (по URL/алиасу/домену, статичные, CSS- или XPath-извлечение).
- Токенизация целевой папки — подстановка полей страницы (`$$field$$`) и служебных токенов в путь.
- Панель настроек закладки за иконкой-шестерёнкой: ручная иконка, теги, категория, статус.
- Заметки, привязанные к закладкам — отдельная вкладка с заметками в виде карточек.
- Каскадное удаление и редактирование расположения закладки прямо с карточки и из панели настроек.

### Исправлено
- Редакторы CodeMirror (JSON/CSS/XPath) игнорировали светлую тему.

### Изменено
- Иконки переведены на обёртки над `lucide-react`; добавлен выбор иконки для категорий.
- Карточка закладки: URL и путь до папки скрыты по умолчанию, крупнее иконка, категория выделена цветом.

## [0.1.0] - 2026-08-18

### Добавлено
- Система правил (DSL в стиле Elasticsearch: `and`/`or`/`not`, `term`/`terms`/`regex`/`wildcard`) для автоматической сортировки закладок по папкам.
- Быстрое сохранение через popup: дерево папок, подсказка тегов/категории по сработавшему правилу.
- Вкладки настроек: Rules, Aliases, Main — с импортом/экспортом настроек единым файлом.
- Тёмная/светлая тема в стиле Obsidian.
